# Galactic Survivor

A space shooter game you play in the browser. Fly through 7 areas, fight bosses, collect skills and power-ups. Built from scratch with HTML and JavaScript.

## Features
- 7 Unique Space Areas
- Challenging Boss Fights
- Skill & Power-up Systems
- Dynamic HUD & Visual Effects

## How to Play
- Open `index.html` in any modern web browser or play the live demo!
